# MEDIA VOGUE — THE FITTING ROOM

Русскоязычная 2D fashion-игра «одевалка»: тест из 5 вопросов, подбор персонажа
и бумажная примерочная с многослойной одеждой. Полностью статичный сайт —
можно публиковать на GitHub Pages без бэкенда.

## Запуск локально

```bash
npm install
npm run dev      # сайт откроется на локальном адресе
npm run build    # сборка в папку dist/
```

## Публикация на GitHub Pages

1. Сделайте форк/загрузку этого репозитория.
2. Соберите сайт: `npm run build`.
3. Загрузите содержимое папки `dist/` на GitHub Pages
   (Settings → Pages → выбрать ветку/папку, например `gh-pages` или `docs`).

Важно: сайт использует **относительные пути** ко всем ассетам
(`assets/...`), поэтому работает и в подкаталоге домена
(`username.github.io/repo/`), и на кастомном домене.

## Структура проекта

```
public/assets/
  characters/<id>/base.png                 — базовый персонаж (600×900, PNG)
  characters/<id>/clothing/<item>.png      — предметы одежды (прозрачные PNG)
src/
  data/characters.ts                       — вопросы теста, персонажи, подсчёт очков
  data/wardrobe.generated.ts               — манифест одежды (позиции, слои, размеры)
  screens/                                 — Welcome, Quiz, Result, Characters, FittingRoom
scripts/generate-placeholders.mjs          — генератор слотов и манифеста
public/assets/README.md                    — таблица всех слотов с размерами
```

## Замена placeholder-иллюстраций на финальные

Каждый PNG-файл в `public/assets/characters/` — это **слот** с точным
именем и размером (см. `public/assets/README.md`). Чтобы заменить
заглушку профессиональной иллюстрацией:

1. Нарисуйте/подготовьте изображение **с тем же именем файла** и
   **теми же размерами в пикселях** (указаны в README и в манифесте).
2. Базовые персонажи — PNG с прозрачным фоном, полный рост, фронтально.
3. Одежда — PNG с альфа-позрачностью, нарисованная точно под эту позу.
4. Просто перезапишите файл — позиционирование, слои и весь игровой
   процесс подхватятся автоматически, без изменений в коде.

Если размеры новой иллюстрации отличаются, обновите `left/top/width/height`
соответствующего предмета в `src/data/wardrobe.generated.ts`
(значения в процентах от сцены 600×900).
